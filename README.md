# 智慧电子班牌（classboard）该项目由AI协助完成

面向高中教室的电子班牌系统：教室一体机展示班级信息、通知公告、天气、签到统计、今日课表、食堂菜单、精选新闻、广播歌单与考试倒计时；管理员在后台维护班级、学生校园卡、公告、课表、新闻、点歌与食堂菜单。

前后端一体化：Spring Boot + Vaadin Flow，界面全部由 Java 编写，无需单独部署前端工程。

> 项目结构、架构分层与功能总览：打开 [`docs/classboard-intro.html`](docs/classboard-intro.html)（单文件、可直接双击）。

## 技术栈

- Java 17、Spring Boot 3.3.4
- Spring Data JPA、Spring Security、Bean Validation
- Vaadin Flow 24.5.0（服务端渲染 UI）
- MySQL 8、Hibernate `ddl-auto: update`
- Open-Meteo 天气接口（免密钥；断网自动沿用本地数据）
- 新华网教育 / 人民网教育 / 中国教育新闻网（教育新闻抓取）

## 快速开始

前置条件：JDK 17、Maven 3.9+、MySQL 8（本机 3306 端口）。

### 一键启动（Windows）

双击项目根目录的 `start.bat`，脚本会自动：

1. 检查 Java / JAVA_HOME 与 Maven 是否就绪；
2. 如果应用已经在运行，直接打开浏览器（不会重复启动）；
3. 执行 `mvn spring-boot:run`，等应用就绪后自动打开浏览器。

```powershell
start.bat                # 正常启动并打开浏览器
start.bat --no-browser   # 只启动，不打开浏览器（服务器/调试时用）
```

数据库口令默认 `root / 1234`，可在 `start.bat` 顶部的 `MYSQL_USER` / `MYSQL_PASSWORD` 处修改，或先设置同名环境变量覆盖。MySQL 没有启动时应用会启动失败，脚本会提示先用 `net start MySQL8.0` 启动服务。

### 手动启动

1. 数据库连接默认 `jdbc:mysql://localhost:3306/classboard`，库不存在会自动创建。
2. 数据库口令通过环境变量覆盖，避免写死在配置里：

```powershell
$env:MYSQL_USER = "root"
$env:MYSQL_PASSWORD = "你的密码"
mvn spring-boot:run
```

3. 打开 <http://localhost:8080>。

首次启动会在**表为空**时写入演示数据：管理员 `admin / admin123`、班级「高一(3)班」、整周课表、3 条公告、设备 `CB-A301-01`；校园生活模块还会写入 46 名学生（校园卡 `2025030101`–`2025030146`）、4 条新闻、3 条点歌、本周食堂菜单、3 天天气兜底数据、3 个倒计时和 5 天值日表。另外会自动补齐高一(1)(2)(4)(5)(6)班，每个班都按班级人数（44–48 名）生成学生与校园卡，并有独立课表和值日表，登录页可直接切换。

- 班牌终端直接访问：`/terminal/CB-A301-01`
- 后台管理：`/login` 右侧卡片登录
- 普通教室浏览器：`/login` 左侧选择班级即可免密进入

> 上线前请务必修改默认管理员口令与数据库口令，并关闭演示数据初始化（或先清空库）。

## 使用要点

- **课表管理**：先选班级，再点击表格中的格子编辑该节课；同一班级 + 星期 + 节次重复保存会覆盖原记录，不会产生重复行。
- **管理员界面**：登录后侧边栏只保留后台管理入口（公告、班级、课表、作业、设备、学生、签到、请假、新闻、点歌、食堂、班级生活），班牌端的大屏、刷卡、点歌与「切换班级」不再出现；顶栏显示「管理员：账号」，退出登录在右上角。
- **班牌终端**：不再显示左侧导航，班牌首页就是功能入口。8 个等大的模块卡片按 2×4 排列（通知公告、天气、今日签到、今日课表、今日食堂、精选新闻、今日歌单、班级生活），每张约为原来的两倍宽；窄屏（≤860px）自动切换为单列，顶栏精简为标题和快捷入口；页面可纵向滚动查看下方卡片，内容超出卡片时在卡片内部滚动；点击卡片弹出详情窗口，右上角「关闭」或 Esc 退出；「今日课表」弹窗内用「本周课表 / 今日作业」两个标签页切换。已经在首页时再点顶栏「班牌首页」会刷新页面并回到顶部。
- **演示班级**：登录页「班级班牌」下拉框有 6 个班可选；每个班都有独立课表、学生卡、值日表和 3 条当日作业，切换后班牌、签到、课表、作业都会跟着变。
- **刷卡签到**：点击班牌「今日签到」卡片，或在 `/checkin` 直接打开；读卡器按键盘方式输入卡号并回车即可，也可手动输入。默认 07:30 前为正常签到、之后记迟到，同一天第二次刷卡记为离校签退。
- **请假登记**：后台「请假登记」选择学生和起止日期；请假期间签到「应到」自动扣除，学生刷卡会提示「今日请假」，无需签到。
- **今日作业**：后台「作业管理」按班级布置；学生在「今日课表」弹窗的「今日作业」标签页查看，也可直接访问 `/homework`，班牌课表面板下方会显示当天作业科目和数量。
- **天气**：点击「天气」卡片可查看未来三天；默认城市杭州，启动后每 30 分钟从 Open-Meteo 拉取，成功更新后班牌会在下一次轮询自动显示；断网或刷新失败时继续显示最近一次数据，恢复后下一个定时任务会自动补齐。
- **广播点歌**：点击「今日歌单」卡片提交点歌，后台「点歌审核」通过后进入班牌今日歌单，播放完可标记「已播放」。后台驳回时可填写原因；驳回的申请不会删除，未读时显示在点歌页顶部「审核通知」，点击「已读确认」后从通知区消失，但仍保留在「本班点歌记录」里；班牌歌单卡片只提示未读数量。
- **新闻详情**：在「精选新闻」弹窗点「查看详情」进入 `/news/{id}`，可查看摘要与原文链接。
- **新闻同步**：后台「新闻管理」点「同步新华网 / 人民网 / 中国教育新闻网」，抓取最近 60 天的教育新闻，之后每 30 分钟自动更新；同步来的新闻可再编辑、配图或下线。
- **公告与新闻配图**：编辑弹窗里可直接上传 png / jpg / gif / webp（≤5MB），也可以粘贴图片地址；上传文件保存在 `uploads/`，通过 `/uploads/xxx` 访问，班牌、列表和详情页都会显示。
- **食堂菜单**：后台按周维护，换周时可点「同步上周菜单」复制，再微调当天菜品。
- **生日祝福**：学生管理里维护生日，当天班牌会自动显示「生日快乐」。
- **公告范围**：编辑器里的「适用班级」留空 = 全校；选择班级后仅该班班牌与公告页可见。删除班级时该班的定向公告会一并删除。
- **公告相关日期 / 有效期**：编辑公告时可设置「相关日期」和「有效期至」。相关日期会作为倒计时同步到班牌「班级生活」（同一天、名称相近的倒计时会自动去重），并在公告列表显示；有效期到点后公告自动下线，后台状态显示「已过期」，班牌和公告页不再返回。考试/活动类公告如果不填有效期，默认在相关日期第二天自动过期；新公告默认有效期 30 天。
- **删除班级**：会连带删除该班课表与班级公告、解绑已绑定设备，操作前有确认弹窗，且不可恢复。
- **大屏刷新**：`BoardView.REFRESH_INTERVAL_MS`（默认 30 秒）。页面通过 Vaadin 轮询拉取最新数据，离开页面即停止轮询。
- **终端部署**：把浏览器设为 kiosk/全屏模式打开 `/terminal/{设备编码}` 即可；服务端会话超时 12 小时，终端不用反复登录。

## 构建与部署

```powershell
# 开发
mvn spring-boot:run

# 打包（开发模式前端，启动时按需构建）
mvn clean package
java -jar target/classboard-1.0.0.jar

# 生产前端（预编译 bundle，首次需联网下载前端依赖）
mvn clean package -Pproduction
```

生产环境建议：

- MySQL 使用独立账号，口令走环境变量；
- `spring.jpa.hibernate.ddl-auto` 从 `update` 改为 `validate`，用 SQL 脚本管理表结构；
- 反向代理（Nginx）转发 8080，配置 HTTPS；
- 定期备份 `classboard` 库，以及 `uploads/` 目录（上传的图片存放在磁盘）。

## 已知限制

- 没有用户管理与自助改密，只有首次启动创建的 `admin` 账号；
- 天气依赖外网，断网时展示最近一次数据或演示数据；
- 刷卡按“读卡器模拟键盘输入”实现，暂未接入学校一卡通/门禁系统接口；
- 请假按整天登记，暂未支持半天/按节次请假；
- 作业只做发布与展示，暂未实现学生提交和教师批改；
- 点歌通知的「已读」按班级保存（班牌端没有学生登录，无法区分到具体学生），同一班级任一学生确认后即视为已读；
- 食堂菜单由后台维护并支持同步上周，暂未对接食堂采购系统；
- 新闻通过抓取新华网、人民网、中国教育新闻网的教育频道列表获取，对方页面结构调整时需要同步修改解析规则；
- 上传图片保存在本机 `uploads/` 目录，多实例部署时需要共享存储或改用对象存储；
- 公告列表未分页，公告量很大时需要补充分页；自动回收采用下线而不是物理删除，避免误删历史记录；
- 后台无操作审计日志；
- 单实例部署；如需多实例，需要会话共享或粘性会话；
- 课表时间以 `HH:mm` 字符串存储，暂未做节次时间模板。

## 常见问题

- **首次登录出现 `Could not navigate to 'hybridaction/...'`**：这是浏览器插件或安全软件向历史记录注入的伪地址，不是系统路由。项目已注册 `hybridaction/:action` 兜底路由，命中后会自动回到首页；如仍出现，可换无痕模式或停用相关插件。
- **点击导航或模块后内容空白**：已修复。原因是 Vaadin 24.5 客户端在轮询间隔为 0 时会抛 `must be positive`，现在离开班牌大屏时改为暂停轮询（1 小时间隔）而不是清零。
- **页面控制台有 `favicon.ico 404`**：不影响功能，浏览器默认请求图标所致。
